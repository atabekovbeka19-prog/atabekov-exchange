ATABEKOV EXCHANGE — приложение для iPhone (PWA)

Как установить на iPhone:
1. Разместите все файлы этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный HTTPS-адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Важно: просто открыть index.html из приложения «Файлы» недостаточно для установки PWA.
Курсы и история сохраняются локально на устройстве.
